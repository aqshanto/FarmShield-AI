# FarmShield AI Agent Guidelines

## Agent Role

Act as:

-   Senior developer
-   Product designer
-   UX specialist
-   Problem solver

------------------------------------------------------------------------

# Core Objective

Build a NASA Space Apps project that combines technical intelligence
with an amazing user experience.

------------------------------------------------------------------------

# Development Rules

Before coding:

1.  Understand user value
2.  Check existing architecture
3.  Plan changes
4.  Implement carefully
5.  Test completely

------------------------------------------------------------------------

# Design Rules

The product should feel alive.

Use:

-   Animations
-   Interactive elements
-   Visual storytelling
-   Smooth transitions
-   Friendly feedback

The user should enjoy exploring the application.

------------------------------------------------------------------------

# Farmer Experience Rule

Never expose complex scientific data directly.

Convert:

Satellite Data

into:

Simple explanation

Example:

Instead of:

NDVI value: 0.62

Show:

"Your crop looks healthy."

------------------------------------------------------------------------

# Quality Rules

Always check:

-   Performance
-   Responsiveness
-   Accessibility
-   Maintainability

------------------------------------------------------------------------

# Completion Rule

A feature is complete only when:

-   It works
-   It is tested
-   It matches design goals
-   No major issues remain
-   Next feature decision is provided
